## 什麼是 DNS 記錄？🤔

DNS 記錄（DNS Record）可以想成一張「資訊卡」。

每個網域都會有很多張不同的資訊卡，告訴全世界：

> 「我的網站在哪？」
>
> 「我的信箱在哪？」
>
> 「哪些憑證可以簽給我？」
>
> 「有哪些其他設定？」

例如：

```
alvinhomelab.idv.tw
```

可能會有：

- A 記錄 → 告訴大家 IPv4 位址
- AAAA 記錄 → 告訴大家 IPv6 位址
- MX 記錄 → 告訴大家電子郵件在哪裡
- TXT 記錄 → 放驗證資訊
- CAA 記錄 → 限制哪些憑證機構可以簽發 SSL 憑證

簡單來說：

DNS 記錄就是一張張「規則」，DNS 伺服器會依照這些規則回答大家的查詢。

## 我們用餐廳來比喻

假設 DNS 是一本電話簿。

那 DNS 記錄就是店家的資訊。

例如我開的店叫

```
🍔 Alvin Burger
```

是不是裡面會寫：

📍 地址

☎️ 電話

🕐 營業時間

🚗 是否有停車場

那同樣地，

DNS 也會記錄：

🌍 IP 位址

📧 郵件伺服器

🔒 憑證資訊

等等。

DNS 伺服器就是依照這些資料回答每一次查詢。
